# ChaoXi / CX 教程排版与润色规范

> **用途**：CX_Product_Tutorials 写教程、润色、出 ChaoXi 风格单页预览时必读。  
> **标准工作流**：**先写章节 `.md` →（站点）Sphinx 发布；或（ChaoXi 视觉）`03-网站系统-勿动/tools/chaoxi_style` 生成 `.html`**。  
> **不采用 `.docm` 作为交付物。**  
> **规范版本**：v1.3-cx  

---

## 0. AI 调用说明（必读）

当用户说「按教材规范」「写教程」「生成 HTML」「润色教程」或 `@` 本文件时：

1. **以本规范为准**，不要 invent 另一套字体/颜色/标题层级。
2. **工作流**：
   - Step A：在 `02-可编辑内容/products/<产品ID>/` 编写或修订 **Markdown**
   - Step B（站点）：`python "03-网站系统-勿动/tools/cx_docs.py" sync` / push 由 CI 构建 Sphinx
   - Step C（ChaoXi 单页视觉）：`python "03-网站系统-勿动/tools/cx_docs.py" preview-html --md <章节.md>`
3. **源稿唯一**：`.md`。ChaoXi **`.html`** 为橙系单页成品/预览；**不要**主动生成 `.docm`。
4. 优先保证：标题层级、品牌色、章节命名、代码与配图占位符合本规范与 §9.2 文风。
5. 润色时：技术含义与步骤顺序不得擅自改动。
6. 文风见 §9.2：言简意赅、手把手、不缺步、不废话、必要配图（`> **[配图]** …`）。
7. ChaoXi HTML 生成后必检：H1/H2/H3 单行；H2 单行橙条；表头橙；代码 10pt；页眉 ChaoXi。

## 3. 字体体系

### 3.1 样式层（Word 样式定义）

| 角色 | 中文字体 | 西文/ASCII | 字号 |
|------|----------|------------|------|
| 正文 Normal | **等线**（DengXian） | 等线 | 继承文档默认约 **10.5 pt**（`sz=21`） |
| 标题 1 | 等线（继承） | 等线 | **22 pt** |
| 标题 2 | **等线 Light** | 等线 Light | **16 pt**，加粗 |
| 标题 3 | 等线 | 等线 | **16 pt** |
| 标题 4 | 等线 | 等线 | 约 **14 pt**（字符样式 `szCs=28`） |
| 标题 5 | 等线 | 等线 | **14 pt**，加粗 |
| 页眉/页脚 | 继承正文 | 继承 | **9 pt** |
| 代码段落样式「代码」 | 等线 / 主题东亚 | — | **10 pt** |
| 列表段落 | 等线 | 等线 | 同正文 |

主题字体：major ≈ Calibri Light；minor ≈ Calibri（西文主题）；实际中文教程以 **等线 / 新宋体** 为主。

### 3.2 正文实际惯用（样张正文 run 级）

样张大量正文直接指定：

- 字体：**新宋体**（NSimSun）为主，部分 **宋体**
- 常见字号：**9.5 pt**（`sz=19`），其次 11 pt / 10 pt
- 对齐：大量左对齐；样式默认虽为两端对齐，落稿时常为左对齐

**写作建议（给 AI）**：

- 新稿样式：正文用 **等线或新宋体 10～10.5 pt**，与样张视觉接近即可。  
- 代码 / 串口输出 / 路径：优先 **Courier New** 或 **Consolas**，10 pt。  
- 不要混用过多英文字体（Arial / Segoe UI 仅偶发，非标准）。

### 3.3 代码着色字符样式（样张内嵌，可选对齐）

| 样式名 | 字体 | 字号 | 颜色 | 含义（惯例） |
|--------|------|------|------|----------------|
| sc0 / sc11 | Courier New | 10 pt | `#000000` | 普通代码 |
| sc101 | Courier New | 10 pt | `#000080` | 关键字等 |
| sc21 / sc12 | Courier New | 10 pt | `#008000` | 注释/字符串类 |
| sc161 | Courier New | 10 pt | `#8000FF` | 特殊标记 |
| sc41 | Courier New | 10 pt | `#FF8000` | 强调 |
| sc31 | Courier New | 10 pt | `#808080` | 次要/注释灰 |
| sc4 等 | 宋体 | 10 pt | 黑 / `#5E6D03` / `#00979C` / `#D35400` | 中文说明穿插 |

无语法高亮时：统一「代码」样式 + Courier New 即可。

> Word 样式名以中文 UI 为准；括号内为 OOXML / 英文名。

### 4.5 标题 4（heading 4）

- 大纲级别：4  
- 文字色 `#E3760C`

### 4.6 自定义引用条（与标题 2 同视觉）

| 样式名 | 用途 |
|--------|------|
| **1级引用** | 目录大标题「Contents」等：橙底白字 16 pt，大纲级别 1 |

- 基于正文

- 基于「无间隔 / No Spacing」

## 5. 目录（TOC）规范

### 5.1 域代码（样张）

```text
TOC \o "1-2" \h \z \u
```

含义：

| 开关 | 含义 | 本教程要求 |
|------|------|------------|
| `\o "1-2"` | 大纲级别 1–2 | **只收标题 1、标题 2**（章 + Project/节） |
| `\h` | 超链接 | 开启 |
| `\z` | Web 视图隐藏页码等 | 开启 |
| `\u` | 使用大纲级别 | 开启 |

**不要**默认收进标题 3/4，除非用户明确要求更深目录。

### 5.2 目录样式

| 样式 | 要点 |
|------|------|
| TOC Heading / 或「1级引用」 | 目录页标题「Contents」 |
| toc 1 | 字号加大到 **22 pt**（与标题 1 同量级）；对应章 |
| toc 2 | 左缩进 420 twip；对应 Project/节 |
| toc 3+ | 每级再缩进 420 twip（样张有定义，目录域未收录） |

页码：右对齐 + 点状前导符（Word 目录默认行为；样张含 `PAGEREF … \h`）。

### 5.3 目录文案结构（命名惯例）

```text
Important Information
Contents
Preface
  └─ 板卡/模块介绍、驱动、软件、环境、GPIO 注意等
Chapter N <主题>
  └─ Project N.M <项目名>
Chapter N+1 …
```

- 章：`Chapter <数字> <英文主题>`（中文版可 `第 N 章 …`，但 CB8201 样张为英文 Chapter 形式）  
- 项目：`Project <章号>.<序号> <名称>`  
- 目录与正文标题必须一致，便于 TOC 域更新

## 8. 列表与编号

常见编号抽象格式：

1. 多级编号：`1.` → `a)` → `i.` …  
2. 中文逗号编号：`1，` `2，`（部分列表）  
3. 项目符号：实心圆点 `●` 等（Wingdings/项目符号）  
4. 纯数字多级：`1.` `1.1` 风格（abstract 中有连续 decimal）

列表正文用 **List Paragraph**。步骤类教程优先 **1. 2. 3.** 阿拉伯数字，子步骤用 a) b) 或子弹。

## 9. 内容结构与文风（润色时遵守）

### 9.1 推荐章节骨架

1. **Important Information**（安全/声明）— 标题 1  
2. **Contents** — 自动目录  
3. **Preface** — 硬件说明、驱动（如 CH343）、编程软件、环境配置、GPIO 注意  
4. **Chapter 0 … Chapter N** — 每章：  
   - 简短原理/元件说明  
   - **Project x.y**（标题 2）  
   - 所需组件（表格）  
   - 电路/接线图  
   - 步骤  
   - 代码  
   - 现象与排错  

### 9.2 文风（长期强制）

- **言简意赅，通俗易懂**：短句、少修饰；能删的形容词、套话一律删  
- **手把手**：按真实操作顺序写（接线 → 软件设置 → 上传 → 观察），读者照做即可完成  
- **一步都不能缺**：凡影响成功的步骤（选板、选口、装库、接线脚位、波特率等）必须写出  
- **一步都不能废话**：禁止空泛背景长论、重复已写过的说明、与操作无关的发挥  
- **必要配图**：电路/接线图、软件关键界面、预期现象等，文中用 `【配图：……】` 标注占位  
- 术语中英统一（如 GPIO、PWM、I2C）；首次可中英并列  
- 警告/注意：单独成段或短列表；只保留关键安全与易错点  

### 9.3 润色检查清单

- [ ] MD：`#` = 章/重要一级，`##` = Project/节，`###` = 小节（Component/Step/Code…）  
- [ ] 目录只突出到章 + Project（对应原 TOC 1–2 级）  
- [ ] HTML：品牌色 `#E3760C`，H2 单行橙条，表格橙系  
- [ ] HTML：代码 Courier New / Consolas **10pt**  
- [ ] HTML：顶栏含 ChaoXi  
- [ ] Project 编号与章号一致  
- [ ] 未改动电路关键连接与可运行逻辑  
- [ ] 步骤完整且无废话；配图已标（MD：`> **[配图]** …` / HTML：`.pic`）  
- [ ] **标题单行**：无空行撑开的橙块
