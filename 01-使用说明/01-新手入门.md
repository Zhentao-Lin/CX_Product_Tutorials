# 新手入门：从零修改教程并发布到网上

这份说明假设你**不会编程也没关系**，只要会：

- 用 Cursor / 记事本 **改文字**
- 在文件夹里 **复制、粘贴图片**
- 在黑色/蓝色窗口里 **复制粘贴几条命令**（下面会给完整命令）

---

## 一、这个仓库是干什么的？

可以把它想成「一本永远在网上更新的说明书」：

1. 你在这个文件夹里写 **Markdown（.md）** 教程和放 **图片、附件**。
2. 你点一下 **推送到 GitHub**（上传）。
3. GitHub 自动帮你 **生成网站**，手机和电脑都能打开。

**你平时要记的两个网址：**

| 叫什么 | 网址 | 干什么用 |
|--------|------|----------|
| **教程网站**（给读者看） | https://zhentao-lin.github.io/CX_Product_Tutorials/ | 手机/浏览器打开就是教程 |
| **GitHub 仓库**（给你改内容） | https://github.com/Zhentao-Lin/CX_Product_Tutorials | 看上传历史、构建有没有成功 |

本地文件夹：`E:\GitHub\CX_Product_Tutorials`（能打开、里面有 `README.md` 就对。）

## 五、手把手示例 1：改一段文字

**目标：** 改 CX0001 第一章里的一段话。

### 步骤

1. 在资源管理器打开：

   `E:\GitHub\CX_Product_Tutorials\02-可编辑内容\products\CX0001_ESP32_S31_Module_Lite_Board\`

2. 用 Cursor 打开文件：`01-overview.md`

3. 文件最上面类似：

   ```markdown
   # 产品概述与适用场景
   ```

   下面都是正文，**像写 Word 一样改字**即可。  
   `#` 表示大标题；`##` 表示小标题（行首加 `##` 再加空格）。

4. **不要删掉** 文件最下面这两行链接（用来返回大纲）：

   ```markdown
   [← 返回本产品教程大纲](index.rst) · [↑ 返回总产品大纲](../../index.rst)
   ```

5. 保存文件：`Ctrl + S`。

6. 按 **第六章** 推送；过 1～2 分钟用手机打开教程网站，刷新看是否更新。

## 十、推送 GitHub（每次改完都要做）

**一句话：** 保存文件 → 在终端执行下面 4 行（可整段复制）。

```powershell
cd E:\GitHub\CX_Product_Tutorials
git add -A
git commit -m "更新教程内容"
git push origin main
```

说明：

- `git add -A`：把所有改动放进「待上传」
- `git commit`：打一包，`-m` 后面是备注（可改成「加了第三章配图」等）
- `git push`：上传到 GitHub

**第一次 push 可能要登录 GitHub**（浏览器或 Git 凭据），按提示操作即可。

### 若提示「nothing to commit」

说明没保存文件，或没改任何内容。先 `Ctrl+S` 保存 .md / 图片，再重来。

### 若 push 失败

把终端里**红色英文**复制下来，再问朋友或把错误发给会 Git 的人；常见是网络或登录过期。

## 十一、怎么知道网站更新成功了？

### 方法 1：直接打开网站

手机或电脑浏览器打开：

**https://zhentao-lin.github.io/CX_Product_Tutorials/**

- 若没变：**强制刷新**（Ctrl+F5）或清除缓存，再等 1～2 分钟（构建要时间）。

### 方法 2：看 GitHub 是否在构建

1. 打开 https://github.com/Zhentao-Lin/CX_Product_Tutorials  
2. 点上方的 **Actions**  
3. 最新一条应是绿色的 **Deploy GitHub Pages site**  
   - 绿色勾 = 成功  
   - 红叉 = 失败（点进去看哪一步报错，常见是某张图路径写错）

### 方法 3：手机「像 App 一样」打开

1. 用手机浏览器打开上面的教程网址。  
2. **iPhone**：分享 →「添加到主屏幕」。  
3. **安卓**：菜单 →「添加到主屏幕」。

## 十二、推荐「最省事」日常习惯

```text
1. 只改 某产品文件夹里的 .md + assets 里的图/附件
2. Ctrl+S 保存
3. 终端执行：git add -A → commit → push
4. 等 2 分钟，手机打开网站看一眼
```

**不必**在自家电脑「编译网站」；编译在 GitHub 云上完成。

装不上 Python 也没关系，以 **push + 手机看网站** 为准。可选 ChaoXi 橙系单页预览：

```powershell
python "03-网站系统-勿动/tools/cx_docs.py" preview-html --md docs/source/products\<产品ID>\01-overview.md --open
```

## 十三、容易踩的坑

| 问题 | 原因 | 怎么办 |
|------|------|--------|
| 图片不显示 | 路径写错或文件没 push | 用 `assets/images/xxx.png`，并确认图片已 `git add` |
| 多出一篇空白页 | 把 .md 放在 `assets` 里 | 章节 .md 只能放在产品文件夹**根目录** |
| 网站还是旧的 | 构建未完成或缓存 | 看 Actions 是否绿勾，再强制刷新 |
| 改了 products.yml 左侧没章节 | 没执行 sync | push 后 Actions 会 sync；本地可先 `python "03-网站系统-勿动/tools/cx_docs.py" sync` |
