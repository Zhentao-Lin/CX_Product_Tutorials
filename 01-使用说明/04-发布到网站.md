# 发布、预览与手机访问

## 目标

- **浏览界面**：`sphinx-rtd-theme`（与 [Freenove 文档站](https://docs.freenove.com/en/latest/) 同类）
- **自动更新**：push GitHub `main` → 站点重建

日常改稿与命令见仓库根目录 [README.md](../README.md)；零基础步骤见 [01-新手入门.md](01-新手入门.md)。

## 方案 A：GitHub Pages（推荐）

1. 仓库已在 GitHub：`CX_Product_Tutorials`。
2. **Settings → Pages → Build and deployment → Source** 选 **GitHub Actions**。
3. 之后每次 push `main`，`.github/workflows/pages.yml` 会 `sync` + `sphinx-build` 并部署。
4. 访问：https://zhentao-lin.github.io/CX_Product_Tutorials/

## 方案 B：Read the Docs（可选）

1. 登录 [readthedocs.org](https://readthedocs.org)，Import 本仓库。
2. 根目录已有 `.readthedocs.yaml`，无需改构建命令。
3. push 后 RTD 自动构建；可绑定自定义域名。

**A 与 B 可同时开**：改教程一次，两处各自更新。

## 手机访问

站点是普通 HTTPS 网页，手机浏览器直接打开即可（无需 App）。

1. 打开 https://zhentao-lin.github.io/CX_Product_Tutorials/
2. **iOS**：分享 →「添加到主屏幕」；**安卓**：菜单 →「添加到主屏幕」
3. 小屏点左上角展开侧栏目录

push 后约 1～2 分钟更新；若仍是旧页，强制刷新或清缓存。可在 GitHub **Actions** 看最新 Deploy 是否绿勾。

## 本地预览（可选）

```powershell
# 推荐（仓库根目录）
.\build.bat
# 或
python "03-网站系统-勿动/tools/cx_docs.py" build --open
python "03-网站系统-勿动/tools/cx_docs.py" serve
```

首次需 Python 3.10+：`pip install -r "03-网站系统-勿动/sphinx-source/requirements.txt"`。

输出：`03-网站系统-勿动/_build/html/index.html`
