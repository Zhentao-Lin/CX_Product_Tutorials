# 教程编辑器使用说明（可视化）

适合不想记 Git 命令时用浏览器完成：**增删改查章节、插图、表格、预览、保存、发布**。

## 启动

```text
双击：E:\GitHub\CX_Product_Tutorials\start-editor.bat
```

首次会安装少量依赖（Flask）。浏览器打开：**http://127.0.0.1:8765**

关闭黑色命令行窗口 = 退出编辑器。

## 三种编辑模式（左侧「编辑内容」）

| 模式 | 作用 |
|------|------|
| **站点总纲** | 编辑首页说明（`02-可编辑内容/catalog/home.md`）；产品列表自动生成 |
| **产品教程大纲** | 改产品标题/状态/简介；可写产品页补充说明（`outline.md`） |
| **章节正文** | 各章教程内容 |

## 功能对照

| 你想做 | 在编辑器里怎么做 |
|--------|------------------|
| **新建产品** | 「＋产品」，填 ID 与名称 |
| **改总纲 / 产品大纲** | 选对应编辑模式 |
| **新建 / 删除章节** | 「章节正文」→「＋章」/「删除本章」→ 再「保存」 |
| 改文字 / 表格 / 代码 | 中间编辑；可用插入按钮 |
| 加图片 | 「上传图片」→ 进 `assets/images/` 并插入引用 |
| 存档 | **保存**（= git add + commit） |
| 上网 | **发布到网站**（= git push → Pages） |

## 保存 vs 发布

- **保存**：只在本机 Git；网站不变。
- **发布**：推到 GitHub，约 1～2 分钟后站点更新。未保存时会尽量先写文件再提交推送。

线上：https://zhentao-lin.github.io/CX_Product_Tutorials/

## 和 Cursor / AI 一起用

1. 编辑器新建或打开章节并保存。  
2. 在 Cursor 里改同一个 `.md` 路径。  
3. 编辑器切换章节刷新，或重启 `start-editor.bat`。  
4. **发布到网站**。

## 安全与排障

- 仅本机 `127.0.0.1`；发布依赖本机已登录的 Git。
- 公有仓勿上传密钥或未公开固件。

| 现象 | 处理 |
|------|------|
| bat 闪退 | 安装 Python 3.10+ 并勾选 Add to PATH |
| 发布失败 | 看命令行 / toast；常见为网络或未登录 |
| 图片不显示 | 已保存+发布；路径 `assets/images/xxx.png` |
| 预览与网站略异 | 以网站为准 |
