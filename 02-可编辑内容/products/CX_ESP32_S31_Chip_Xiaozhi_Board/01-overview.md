# 产品概述与 BOM 差异

芯片版小智板：主控用 ESP32-S3 **芯片**（非成品模组），外围你自己控。适合要改板、压成本的阶段。

## 本章目标

1. 明白芯片版和模组版差在哪。
2. 知道 BOM 上要多盯哪些料。
3. 决定当前项目该不该用芯片版。

## 什么时候选芯片版

| 更适合芯片版 | 更适合模组版 |
|--------------|--------------|
| 要改射频/天线/外围 | 先出功能样机 |
| 要压 BOM 成本 | 课堂 / 快速验证 |
| 已有贴片与调试能力 | 少焊接、少射频细节 |

## 和模组版的差异（选型）

| 项目 | 芯片版 | 模组版 |
|------|--------|--------|
| 主控形态 | 芯片 + 你的晶振 / Flash / 射频外围 | 模组已集成大部分 |
| 贴片难度 | 高 | 低 |
| 改板自由度 | 高 | 中 |
| 教程节奏 | 先原理图与 BOM，再功能 | 先上电与功能 |

## BOM 你要多看的几项

| 类别 | 注意 |
|------|------|
| 主控芯片 | 封装、温度等级与供货 |
| Flash | 容量、封装与接线 |
| 晶振 | 频率、负载电容 |
| 射频 / 天线 | 匹配与净空 |
| 电源 | LDO/DCDC 电流与纹波 |

> **[配图]** BOM 表截取（电源 + 射频相关行）

## Step：选型自检（五问）

1. 当前目标是「先跑通」还是「改板量产」？
2. 有没有贴片与焊接条件？
3. 天线方案是否已定？
4. Flash 容量是否够固件？
5. 若以上有多项不确定 → 先用模组版出样，再转芯片版。
