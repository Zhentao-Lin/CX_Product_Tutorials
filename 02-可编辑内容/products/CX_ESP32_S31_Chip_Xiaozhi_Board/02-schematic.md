# 原理图要点说明

芯片版原理图按块看：供电 → 时钟 → Flash → 射频 → USB/下载 → 音频与其它外设。

## 本章目标

1. 会按「块」读芯片版原理图。
2. 知道每块最容易错的点。
3. 为打板 / 改版留下检查清单。

## 阅读顺序（推荐）

1. 电源输入与 3.3 V。
2. 复位 / 下载（EN、BOOT 等）。
3. 晶振。
4. Flash。
5. 天线与射频通路。
6. USB 与串口下载。
7. 音频与其它 GPIO 外设。

> **[配图]** 原理图总图缩略（分块标号 1～7）

## 分块注意点

### 电源

| 检查 | 说明 |
|------|------|
| 输入范围 | 与 USB / 电池方案一致 |
| 3.3 V 电流 | 模组/芯片峰值预留余量 |
| 去耦 | 靠近芯片电源脚 |

### 晶振

| 检查 | 说明 |
|------|------|
| 频率 | 与芯片要求一致 |
| 负载电容 | 按晶振规格，勿照抄别板 |

### Flash

| 检查 | 说明 |
|------|------|
| 接线 | CLK / CS / IO 无交叉 |
| 容量 | 满足固件与资源 |

### 射频

| 检查 | 说明 |
|------|------|
| 匹配网络 | 按天线方案 |
| 净空 | 天线下方少铺铜、少走线 |

> **[配图]** 电源与射频局部原理图（可两张）

## Step：改版前检查清单

1. 打开当前版本原理图 PDF。
2. 按上面 7 块顺序勾选「已核对」。
3. 与 BOM 交叉：每个关键位号在 BOM 有料。
4. 与 PCB 交叉：射频净空、USB 座方向、丝印。
5. 记录差异到改版笔记（一句话一条）。

## 下载

公开资料目录：`assets/hardware/schematic/`（约定见根目录 README）。  
完整源工程用私有仓，勿把未公开源文件放进本公开教程仓。

## If It Fails

- 仿真 / 实测供电不稳 → 先查输入、LDO 发热与去耦，再查负载。
- 无法下载 → 查 BOOT 电路、USB 转串口、EN 时序。
