# 产品概述与适用场景

模组版小智板：主控用 ESP32-S3 模组，少焊接、好上手，适合语音交互与物联网原型。

## 本章目标

1. 知道模组版适合做什么。
2. 分清模组版与芯片版怎么选。
3. 看清板上主要接口（为后面接线做准备）。

## 适用场景

| 场景 | 说明 |
|------|------|
| 小智 / 语音助手原型 | 模组 + 音频链路，先跑通再改 |
| IoT 联网演示 | Wi-Fi / 蓝牙联调 |
| 课堂与培训 | 步骤短，少踩焊接坑 |

## 模组版 vs 芯片版

| 对比 | 模组版（本章产品） | 芯片版 |
|------|-------------------|--------|
| 上手 | 快 | 需更熟硬件 |
| 成本 | 模组成本偏高 | 量产更易压成本 |
| 定制外围 | 够用 | 更自由 |
| 推荐读者 | 先做功能、先出样机 | 要改板、要控价 |

## 板上你先认这些

| 名称 | 作用 |
|------|------|
| USB | 供电与烧录 |
| 主控模组 | ESP32-S3 |
| 音频相关接口 | 麦 / 喇叭（以丝印为准） |
| 指示灯 / 按键 | 状态与输入 |

> **[配图]** 丝印标注图：USB、Boot、Reset、天线位置

## Step：第一次上电检查（不断线版）

1. 准备数据线（需能传数据，不建议仅充电线）。
2. 板子先不接其它外设。
3. USB 插入电脑，看是否枚举出串口（设备管理器 / 系统信息）。
4. 若无串口：换线、换口，确认驱动（见后续驱动章节）。

## If It Fails

- 电脑不认串口 → 换数据线；装/重装 USB 转串口驱动。
- 上电无反应 → 换 USB 口；确认板载供电指示（如有）。
