# 硬件架构与模组选型

本章看清：电从哪来、主控是谁、音频与常用外设怎么连到模组。

## 本章目标

1. 看懂模组版硬件框图。
2. 知道选型时要盯的模组参数。
3. 为下一章接线留下脚位习惯（以丝印 / 原理图为准）。

## 硬件框图（逻辑）

```text
USB ──► 供电 / 下载
          │
          ▼
     ESP32-S3 模组 ──► Wi-Fi / Bluetooth
          │
          ├── 音频编解码 / 麦 / 喇叭
          ├── 用户按键 / LED
          └── 扩展排针（GPIO）
```

> **[配图]** 硬件框图（与上表一致，可手绘或导出）

## Component List（读板用）

| 名称 | 说明 |
|------|------|
| ESP32-S3 模组 | 主控，含 Flash（以实际料号为准） |
| USB 座 | 供电 + 烧录 |
| 音频器件 | 麦、喇叭或功放（以 BOM 为准） |
| 按键 / LED | 复位、Boot、状态指示 |

## 模组选型时看什么

| 项目 | 你要确认 |
|------|----------|
| 封装 / 焊盘 | 与 PCB 库一致 |
| Flash 容量 | 够放固件与资源 |
| 天线 | PCB 天线或外置；摆件避金属遮挡 |
| 供电 | 3.3 V 轨与电流余量 |

> **[配图]** 模组丝印与天线净空示意

## Step：对照实物认模块

1. 断电，拿出模组版板子。
2. 找到 USB 座与主控模组。
3. 找到麦 / 喇叭接口或焊盘（有则认，无则看原理图）。
4. 找到 Reset / Boot（命名以丝印为准）。
5. 在笔记本上记下：「USB → 模组 → 音频 / 按键」这三块位置。
