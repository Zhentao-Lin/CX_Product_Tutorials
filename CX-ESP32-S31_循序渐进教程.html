① 预备与环境② 外设基础③ 存储与音频 ④ 摄像头⑤ Wi-Fi⑥ 蓝牙 ⑦ 扩展板实验⑧ 进阶与综合
重要前提：ESP32-S31 目前由 ESP-IDF master 分支支持（v5.4+/v6.0-dev），官方开发板为 ESP32-S31-Function-CoreBoard-1、ESP32-S31-Korvo-1；部分外设示例仍在完善，可借助 espressif/esp_board_manager 复用官方 S31 板级配置。每节下方灰字为对应的乐鑫官方示例/组件。
发布去向：各篇写完后同步到 CX_Product_Tutorials 产品 CX_S31_Mini_Xiaozhi（在线： GitHub Pages）。 提炼版见 路线图 · S31 48 节；同步流程见同页「教程站」。
结构约定：第一~六篇、第八篇只用开发板自身（含插在板载接口上的喇叭 / TF 卡 / 摄像头 / U 盘等配件）； 第七篇「扩展板实验」需一块配套扩展板（集成电位器、光敏、I2C 传感器/OLED、Touch、SPI TFT 屏、电容触摸屏、USB-TTL）。
