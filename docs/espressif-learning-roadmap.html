超析小智 · 产品架构与学习路线

五类产品主线：2×S31 → P4 七寸 → 外设 → S3 互动（5a 狗 / 5b 摆件 / 5c 小车）。学习阶段 L0～L5；每 SKU 循序渐进见 L1·48 节 与 L2～L5 课纲。

产品架构 硬件顺序 学习路线 L1·S31 L2～L5 教程站 阶段课表 学习闭环 官方示例 验收 链接
先做 2 块 S31：① 最小系统板（走线 v1.1 + 配套固件与教学站，单板回血）② Mosaico 兼容廉价版（跟官方 xiaozhi board，少维护）。
然后 P4 七寸 MIPI → ESP 外设 → 第 5 类互动：5a 机器狗 · 5b 桌面摆件 · 5c 多功能小车（同定位，可并行）。

  1. 安装 ESP-IDF（S31/P4 目标），跑通 examples/get-started/hello_world、idf.py menuconfig / monitor。

  3. 建立 KiCad 工程：符号/封装用 kicad-libraries；高速/音频规则查硬件设计指南。

产出：统一 IDF 版本说明、引脚表 v1、双 S31 SKU 命名规则。
